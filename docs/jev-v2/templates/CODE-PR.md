使用实际改动标题，不创建仅含TODO的占位PR。删除提示性示例后填写，任务进度以Issue为准。

请求的审查范围：

本PR部分完成不得自动关闭整个批次。未经批准不merge/deploy；文档/编译/模拟成功不能冒充功能、设备或真实质量验证。
