## 已验证行为

- **B04-T03 typed primitives**：`RawAnswer.UnmarshalJSON` 按声明类型解析内联 noul/choice/score；缺字段、未知类型、概率越界、分布不匹配、额外字段、重复键、尾随 JSON 均返回 **contract** 错误（不静默产生空标签）。`DescribeDistribution` 保留 max/entropy/runner-up/margin，不把分布折成单一数字。
- **B04-T04 question compiler**：`CompileSpec` 从版本化 catalog 生成 ordered `[]Question`；topic 用独立 Noul，form/use 用 Choice，Score 仅在 `scoreEnabled` 时加入。question ID 只作稳定句柄，语义在 `Instructions`/`Criteria`/`Levels`。
- **B04-T05 客观证据**：`PrepareEvidence` + `stateForModel` 物理排除 note/why/status/stance；`TestObjectiveStateExcludesPersonalFields` 断言实际出站 HTTP body 不含备注内容。角色区分 primary/author_continuation/quoted/third_party/external/legacy_unknown。
- **B04-T06 预算**：按 rune 保守上界（明确不冒充精确 token），primary 优先，超出记录 `truncated`/coverage，不截断 JSON，不把未发送材料当已评估。
- **B04-T07 纯 policy**：`Decide` 逐字段 accepted/rejected/**abstained**；合法 `none`/empty 为 completed；单个模糊候选局部弃权，不污染整条（`TestLocalAbstentionDoesNotContaminateOtherFields`）。reason 来自可观察依据。
- **B04-T08 margin/confidence/Score**：`MarginHasNoIndependentPower` 边界测试证明归一分布下 `best>=0.65` 蕴含 margin 规则；置信度只作分布特征、不与 p 相乘；Score 同 ordinal、分布保留。
- **B04-T09 上限解耦**：`MaxEffectiveTopics`（安全上限）与 `MaxDisplayTopics`（卡片折叠）分开；`PartitionTopics` 折叠不删除第四个有效 topic。
- **B04-T10 与 B03/B01 连接**：`cairn` 客户端 `CompleteClassification` 携带 `spec_id`、`input_revision`、`target_generation`、operation key；`ClaimClassification` 绑定握手目标；`PolicyVersion` 更新为 `jev-policy-v2`。
- **B04-T11 离线 replay**：新增 CLI `replay`（读 stored run → 纯 Decide → diff，默认 **不提交**、模型调用 0）与 `refresh-source`（显式重取，与 replay 分离）。`DecodeStoredJudgments` 对无快照返回 `ErrNoReplayableRun`，不编造。
- **B04-T12 增量/cache**：`CacheKey` 含 evidence/spec/model/batch 语义；跨 model/跨 spec 不可复用（测试断言）。
- **B04-T13 个人意图**：客观请求不含 note；why 建议由程序模板构造，不冒充真实动机。
- **B04-T14 运行边界**：复用 B02 typed errors；`RunClassifications` 对 configuration/contract 暂停组件、对 stale 不计失败、对 already_completed 记成功。
- **B04-T15 测试**：表驱动策略场景、边界/fuzz 式取值、HTTP mock fixture、禁网 replay。
