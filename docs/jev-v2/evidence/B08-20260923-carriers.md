## 工程合同与身份

原 single 仅排除续帖，与外链正文重叠；unknown 与 none 又都描述证据不足。生产 Worker 词表升为 **definition_version=2**，仅载体定义/正反例变化，旧 ID/显示名及 17/7/5 词表不变：

1. 已提供且确认同作者关联续帖正文，优先 `author_continuation`，包括同时有外链正文的情况。
2. 否则，已提供原帖关联的外部文章正文，选择 `external_article`；入口存在一条原帖不再使 single 同时匹配。
3. 否则，可观察的原帖为 `single`。引用、他人评论、普通链接不当作作者续帖或已取得外链正文。
4. 正文不足或关系未确认是 `unknown`；可观察但不属于词表的结构是问题的 `none`。只有 URL/标题或 1/n 字样不伪称已获得正文/续帖。范围是当前提供材料，不宣称抓取完整。

Go 在存在活动 unknown 候选时区分 none；没有 unknown 的旧简化词表继续保留原不足证据分支。其他问题、状态构造、默认 **jev-policy-v3** 和阈值未改。旧完整客观问题对象另存为 [objective-use-spec.json](../../../experiments/classification/reference-v1/objective-use-spec.json)，此前个人意图实验继续比较不可变历史对象，当前 use 与该历史新 use 一致。
