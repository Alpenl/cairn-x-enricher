## 已复现和修复

[修复前日志](logs/20260923-gate/b08-gate-baseline.log)保留 22 个失败场景：非法阈值六项、非法报告或训练/dev 晋升七项、不可比消融七项、基线独有维度消失和零 Brier 限制被绕过各一项。使用独立生成的 30 组工程样本，经实际 `Score` 生成报告；未使用真实冻结 dev/holdout，也没有网络或付费调用。

- 冻结 gate 的样本和独立组门槛必须为正，概率限制为有限 `[0,1]`，六字段复核负担限制为有限 `[0,6]`。零错误/Brier 限制仍是严格零值，不能作为关闭检查的哨兵。CLI 在选择执行模式前校验 gate；live 和恢复函数也在读取各自输入前独立校验，非法 gate 不会触发模型调用。
- `EvaluateGate` 要求 holdout split、合法参考和数据摘要、合理样本/组/字段计数及与计数一致的 coverage；拒绝超范围或非有限指标。train/dev 仍可评分、拟合，但不再输出 `promote=true`。统计不足仍 inconclusive。
- 消融比较要求相同冻结参考摘要、split、样本与组规模、相同单/多选任务语义及有效且相同的参考支持。不同预测会改变 DatasetHash，因此不错误地要求预测相关摘要一致。缺失、重复、无支持、非法 F1 明确不可比；保留两侧维度并集，失败原因可读，不计算无意义差值。非法浮点输入也能序列化诊断。
- `Comparable=true` 只说明指标可以比较，**不证明只改了一个实验变量**。问题/spec/model/state 和 intervention 的受控绑定仍由后续实验 runner 完成；不得将此函数当成完整消融验收。
