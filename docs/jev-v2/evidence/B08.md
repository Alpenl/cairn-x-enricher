## 变更

新增独立离线包 `experiments/classification`（不挤入生产包）：

- **B08-T02 数据 schema/校验**（`dataset.go`）：`Sample` 含 sample_id、source_hash、revision、
  language/carrier/length/completeness、group_id、检索相关性、多标签 gold（含
  `not_applicable`/`unknown`）、`Provenance`、ambiguity、第二标注者标记。
  `Validate` 拒绝重复 sample_id、缺 source_hash、缺 provenance，并拒绝 `legacy_unknown`
  携带 gold（旧隐式 reviewed 不是自动正样本）。`NormalizeLanguage` 归一化中英混合分层。
- **B08-T05 分组切分**（`SplitByGroup`）：先按 thread/近重复 group 聚合，再以 seed 的稳定
  哈希分配 train/dev/test，保证同组不跨集合。
- **B08-T06 纯离线 scorer**（`score.go`）：每维 precision/recall/F1、micro/macro、
  accepted error、coverage/abstention、review fields/条、按语言/长度/载体分层计数、
  support 与缺失 gold 计数。零分母显式规则（0/0=0，绝不等于满分）；多标签不使用单类 accuracy。
- **B08-T07 校准**：从保存的 topic 分布计算 Brier 与 ECE（10 分箱）+ 非空箱数，披露分箱限制；
  分布差异不会被折成单一数字。
- **B08-T08 阈值重放与搜索**：`Replay` 从存储概率重算 accepted（零模型调用）；
  `SearchThresholds` 仅在 train 上拟合并遵守 coverage floor。
- **B08-T09 消融比较**：`CompareAblations` 对基线缺失的维度标 `Comparable=false`，不做异任务相减。
- **B08-T13 晋升门禁**：`GateThresholds` 冻结风险/coverage/负担/成本门槛；accepted error 作为
  安全指标独立于 recall 检查；样本不足 → `inconclusive` 且不晋升；
  `DetectModelDrift` 对 alias 漂移要求重新评估。
- **B08-T14 报告与 CLI**：`experiments/classification/main` 提供 `-dataset`/`-gate`/`-dry-run`；
  `-dry-run` 输出计划且 `model_calls: 0`；`-live` 需要显式正数 `-max-calls` 预算且本构建
  明确拒绝（未启用 live runner），环境有 key 不等于授权。
- **合成 fixture + golden vector**：`testdata/synthetic-dataset.json` 与两个 golden 测试固定
  报告形状、哈希稳定性与可重复性。

关键断言：零预测/零正例不是满分；全弃权不能换漂亮 precision；合法 none 计为 support 且非
错误；micro 与 macro 在不均衡样本下不同；过度自信分布产生大 ECE/Brier；重复 sample 被拒；
legacy_unknown 不能带 gold；分组切分不泄漏；阈值重放零调用；消融对不可比维度标记；
安全失败即使统计良好也阻止晋升；缺 gold 标记 inconclusive；无真值不输出 accuracy。

- 模型调用计数：0（全部离线；live 路径被显式拒绝）。
- 数据隐私：fixture 为合成数据，不含私人原文/备注/实体/标注。
