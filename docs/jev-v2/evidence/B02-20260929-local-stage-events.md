# B02-T07 / OBS: local source-stage lifecycle events

The Go scheduler now emits fixed, privacy-filtered events for a local source or reading configuration/contract pause, the first skipped claim for each paused stage in a round, the start and outcome of a half-open probe, and a local lease deferral after a pause races with a claim. The pause event contains only a stage, error class and backoff length. Probe and claim events contain only stage and outcome. The optional asynchronous exporter still uses the existing off/basic/diagnostic hot policy and bounded queue; an off policy prevents these events from entering that exporter.

A provider configuration/contract error trips the local stage pause before Go reports the job failure to Worker. The pause therefore remains effective if that report fails. The failure is still surfaced to the scheduler. A recovered panic resolves its half-open probe as failed and emits that outcome. An older probe that loses its epoch reports `stage_probe_superseded` rather than claiming to have closed a newer fault. Each paused stage produces at most one skip event per scheduler round, regardless of how many other-stage jobs are claimed.

Verification: targeted processor and observability tests cover stage isolation, pause/probe/skip event fields, redaction of a private provider error, and pause persistence across a Worker failure-report outage. `make verify` includes lint, race tests, 488 frontend checks and a build. The paired Worker evidence covers the persisted lease-release events; a real local Go→Worker/D1 integration exercises the two-stage path.

Limits: these exported events deliberately omit bookmark, operation and lease IDs because stdout or a collector may lack per-bookmark deletion. The deletable Worker ledger and receipts remain authoritative for individual paid attempts. The existing exporter can drop records when its bounded queue fills; production reconciliation, separate metrics/traces controls, and the 14-day observation report remain open. No real supplier request or remote deployment occurred.
