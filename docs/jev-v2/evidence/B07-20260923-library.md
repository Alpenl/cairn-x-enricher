## 修复结果

Android 收藏库此前只在输入关键词后调用服务端筛选；无关键词时对本地 v1 摘要过滤，第四主题、隐藏维度及本地快照之外的收藏会漏掉。现在激活收藏筛选或待读/已读条件时，使用独立的服务端分页结果集，保留根列表作为队列/统计快照；不再用 v1 DTO 或已加载的部分 v2 详情猜测集合成员。

四个分类维度和独立实体状态都有多选控件；同维 OR、跨维 AND，未知/停用保存项保持可见，词表在同步时加载。收藏库与搜索请求完整语义条件时均协商 `filter_contract_version=1`，缺少/null/未知/字符串版本可见拒绝；清除条件可继续旧服务普通浏览。筛选或搜索失败不再被空列表文案掩盖，有重新查询入口。

查询保存固定的相对日期边界，后续分页不随时钟漂移；分页必须按正 ID 降序推进，空页带 cursor、重复或回退 cursor 可见停止。过滤变化、确认的保存/删除/整理/上传、账号切换取消旧集合和 cursor；请求代次、账号代次及条件共同检查迟到响应。确认动作重新读服务端成员，离线草稿不改变已保存筛选结果。根列表的显示数量标明“已加载”。

本批无新增数据库迁移、Go 或 Worker 运行时改动；使用前批 Worker 的完整有效历史查询及显式能力确认。
