# B02-T07 来源与阅读阶段门闩：本地证据

2026-09-29。代码与对应 Worker 变更须一起评审和按先 Worker、后 Go 的顺序发布；本记录只证明本地实现，未执行生产迁移、部署或付费调用。

## 合同和故障边界

- Go 在启动握手中要求 `source_component_gate`，避免新处理器接到尚未保护来源/阅读阶段的 Worker。来源获取和阅读生成分别在付费准入前声明阶段。
- 来源或阅读的暂时性供应商故障携带阶段、最多 10 分钟的 Retry-After 给 Worker；Worker 将当前任务失败和相应门闩打开写在同一 D1 batch 中。普通内容/合同错误仍按单条任务处理。
- 门闩在领取前筛选候选。已存原文且无刷新意图的任务可在来源暂停时继续阅读；等待中的来源任务不消耗 attempt。领取和到期后的单个半开探测所有权由同一 D1 batch 处理。旧租约即使在门闩打开前领到，也无法在打开后预留新的付费调用。
- 来源成功保存且匹配已结算的成功抓取，或阅读成功提交且匹配已结算的阅读调用，才关闭各自探测。仅保存人工/遗留原文不会宣称来源供应商恢复，并释放该探测供下一条真实抓取接手。

## 验证

- `make verify`：vet、golangci-lint、全包 race/coverage、前端 488 项和构建通过。
- Worker 39 个测试文件、413 项通过；`tsc --noEmit` 和 Wrangler dry-run 构建通过。来源租约定向用例覆盖来源/阅读互不阻塞、唯一探测、旧消费者不能接手探测、付费前门闩、故障重开与成功关门，以及无供应商调用的探测释放。
- 真实本地 Go→Worker/D1：`CAIRN_INTEGRATION_CASE=sourcegate tests/local-integration/run.sh` 通过。合成 529 经 Go 阶段化上报后，新建的人工原文任务仍完成阅读；另一个待抓取任务保持 `attempts=0`，领取返回 `component_paused`。`sourcelease` 既有联调用例也通过。两项均无真实供应商请求。
