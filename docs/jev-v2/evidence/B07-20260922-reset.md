## 行为与迁移

- Go / Worker 在单标签 reset 时解除显式 empty 标志，同时保留 cleared-automatic 屏障，仅重新允许该标签。其他自动标签继续被屏障抑制；整字段 reset 仍恢复整个自动基线。复归的值不被标成人工接受。即便该标签暂时不在自动基线，也不再显示为人工明确空值。
- 两仓共享 33 个动作向量，新增七个维度的清空后单标签重置。旧 E `3520dc1` 加入同样七条回归后全部失败、原 26 条通过：[原失败对照](logs/20260922-state/reset-known-failure.log)。Android 原本已经预览恢复值，本批使服务端读回与其一致；新增 unit 验证两个自动主题中仅恢复一个。
- 新迁移 `0024_per_term_reset.sql` 重建 `effective_entity_terms`。实体只使用匹配当前 link/content revision、snapshot ID/hash 的独立成功结果；支持历史 `entity` 单数别名，事件顺序与运行时一致，按 revision/id 而非只按插入 ID。搜索的旧 classification.entities 回退同样识别历史别名。
- 历史修复只匹配最后一个非单标签重置动作为 `set_empty`、之后发生过单标签重置的字段。纳入最近 legacy_unknown 层，其同版本动作先于真实 override。之后已有 accept/reject/整字段 reset 的字段不修。读取当前真实自动基线，仅恢复被指定 reset 的词，保留源顺序及单载体限制。
- 迁移就地修补已有 `current_projections`、`link_selections_v2` 和 v1 `links.curation` 的受影响值；六维 empty 标志同步解除，v1 主题仍遵守三项兼容上限。保留其他缓存字段、元数据、来源和版本，不凭空补造缺失缓存。更新 curation 时同事务增加 projection epoch，避免旧版捕获触发器制造人工事件。
- 人工事件、legacy 原文、个人/内容版本、分类运行和决定、AI classification、实体和证据记录全部保持原样。本批没有执行生产迁移，也没有重新调用模型补历史数据。
