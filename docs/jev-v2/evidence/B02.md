## 已验证的具体行为

- **B02-T01/T02 显式确认**：`internal/dashboard/reader.js`、`reader.html`。原因/状态与标签分别维护 dirty；只有实际触碰标签或点击“确认这些标签”才在 PATCH 中发送 `classification`。`frontend-check.mjs` 断言 why-only / status-only / why+status 保存均不含 `classification`；显式取消勾选与显式确认两条路径必须携带。新增“dirty 草稿不被轮询覆盖”回归。
- **B02-T03/T04 独立 ReadingResult**：`internal/enrich/responses.go`（`readingSchema`）、`internal/enrich/source.go`（`Transform` → `decodeReading` → `validateReading`）。阅读 schema 独立定义；模型只输出 title/language/translation/summary，原文/链接/图片由程序从已存快照注入。缺失字段、尾随内容、非 JSON、未知键、尝试重写原文均显式失败。
- **B02-T05 B01 握手接入**：`internal/cairn/stages.go` 新增 `Handshake`、`Capabilities`、`ClassificationTarget`、`ClassificationCapabilities`、`SpecID`。`ClaimClassification` 先查询权威目标并声明能力，再以目标绑定 claim；不支持的目标返回组件级 configuration 错误。serve/once/classify 共用同一 `Client` 路径。
- **B02-T06 typed 错误分类（模型侧与 Worker 侧）**：
  - `internal/enrich/errors.go`：401/403/402 → configuration，400/422/415 → contract，408/429/5xx → transient，409 → stale；`ClassOf` 支持其他包通过 `Class() ErrorClass` 自分类。
  - `internal/cairn/client.go`：`APIError.Class()` 按 Worker 的 typed code（`capability_mismatch`/`configuration_error` → configuration，`target_changed`/`input_changed`/`lease_expired` → stale，`already_completed` → completed，`operation_conflict`/`invalid_*` → contract）与状态码双通道映射。
  - `internal/classify/jev.go`：TypeSafe HTTP 状态与畸形/尾随响应按类返回，不再统一成 `HTTP %d`。
- **B02-T07 单一持久化退避层与组件暂停**：模型侧仍由 `internal/enrich/responses.go` 单层有界退避（上限 3 次、`Retry-After` 尊重且封顶、jitter、慢请求不再叠加）。新增 `processor.RunClassifications`：configuration/contract 错误**暂停组件**（不 `FailClassification`、不计失败、不耗尽 attempt）；stale 不记模型失败；`already_completed` 记成功。健康由既有 `internal/health` 分组，liveness 不依赖外部 API。
- **B02-T08 幂等提交与有界 shutdown**：`internal/cairn/stages.go` 新增 `ClassificationOperationKey`（`classify-<id>-rev-<r>-input-<ir>-gen-<g>`）与 `input_revision`/`target_generation` 字段，`CompleteClassification` 携带 operation key；`FailClassification` 携带 input/target 供 supersede 判定。`RunClassifications` 用 `context.WithTimeout(context.WithoutCancel(ctx), DefaultClassificationDeadline)` 替代无限 `WithoutCancel`，shutdown 有上限且不再领取新任务。
- **B02-T09 角色化配置**：`internal/config/config.go` 的 `Role`/`LoadFor`；`classify` 只校验 Worker + Typesafe。`cmd/.../classify.go` 用 `RoleClassify`。
- **B02-T10 source-first**：`internal/processor/stages_test.go` 回归（source 先存、阅读失败重试不重抓、分类失败不触发 X Search、阅读不写 classification）保持通过。
- **B02-T11 回归**：`make verify`、`make test-ablation`、前端 DOM shim。
