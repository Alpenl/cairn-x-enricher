## 本轮可重复的失败证据

`go run ./tests/acceptance/budget-probe` 调用生产 `Service.RerankCandidates` 两次，仅替换 Judge 为无网络计数器。配置总调用上限 1，实测调用 2，退出码 **1**；[原始日志](scope-20260923/budget-gap.log)。这是 G01 的失败证据，不能记为通过。默认关闭不代表启用后的预算已完成；此探针不测持久账本、token 估算或付费 API。

结构检查命令：`python3 tests/acceptance/validate_scope.py`。它只检查编号、原文、映射、链接/文件摘要的一致性；不执行功能验收。`--check-git` 还读取两仓固定 git 对象验证摘要。普通 `make verify` 编译诊断命令但不运行它，不能据此掩盖已知失败。
