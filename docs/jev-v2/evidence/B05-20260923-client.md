## 行为与合同

此前 Worker 已支持完整有效标签筛选，但 Go `BookmarkQuery` 和 dashboard 解析器丢弃新增维度，Web 首页也没有相应多选入口。现在 Go 转发 `topics/content_functions/carriers/affordances/entity_state`，保留同维 OR、跨维 AND；主题旧 `topic` 与新 `topics` 仍按 Worker 合同合并。解析器拒绝空分项、重复参数和超界/非法状态，具体词表 ID 的存在与历史停用语义由 Worker 权威判断。

Web 首页提供四个分类维度及实体状态多选，无关键词也通过服务端查询；旧单主题 URL 恢复为主题多选。筛选变化取消旧请求、清空旧 cursor 并重新查询，URL 保留条件；清除筛选同时清空控件。词表加载失败保留已请求条件并提示，未知保存 ID 可见。375px 窄屏多选框不溢出。列表和服务端 Markdown 导出传递相同条件，未把当前页称为全库备份。

客户端需要完整筛选语义时发送 `filter_contract_version=1`。两个 Worker 列表入口仅在明确请求时返回数值 `1`；未请求时完全保留旧响应字段。App 缓存键区分该参数，重复/空/不支持版本返回 400。Go 对新维度自动要求确认，也允许旧参数显式 opt-in；收到无字段、null、0 或未知版本时拒绝，dashboard 返回 `409 unsupported_filter_contract`。Web 对自身请求再核对确认字段，显示更新服务或清除筛选的可见提示。旧服务普通浏览仍可使用；不将旧服务忽略条件后的宽泛结果当作筛选成功。

本批未修改数据库迁移或模型语义。此前权威历史筛选、0025 缓存失效及性能限制见 [Worker 报告](B05-20260923-filter.md)。
