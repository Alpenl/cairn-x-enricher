## 变更

新增独立包 `internal/extension`，四个能力各自独立 flag、**默认全部 off**：

- **B09-T01 flags/预算/去重**（`flags.go`）：`Flags`（entities/evidence/rerank/proposal）默认 false；
  `Budget`（每条/总量调用与 token、timeout）与 `Ledger.Reserve` 在超限时返回
  `ErrBudgetExhausted`，用户内容或模型答案无法提高额度；`DedupeKey` 含 kind/scope/revision，
  重试按 key 复用而不重复计费。
- **B09-T02 候选提取**（`entities.go`）：`ExtractCandidates` 纯本地从已存档 block 文本提取
  surface 及**精确 rune span**（测试断言 span 可回指原文字符串），并从**已存在链接**直接
  surface URL；候选数量与最小长度有界；不重新 X Search、不让模型自由造名。
- **B09-T03 受限判断**：`ValidateVerdict` 拒绝候选集外的 surface、受控集合外的 canonical 与
  非法 decision；`none`/`unknown` 合法；同名为空 canonical（不自动合并）。
- **B09-T06 受控外链适配器**（`fetch.go`）：`FetchPolicy` 显式 allowlist（空 allowlist 拒绝一切，
  无“允许全部”模式）；`ValidateURL` 拒绝非 http(s)、含凭据、非标端口、IP 字面量与非白名单主机；
  `DialGuard` 在**实际拨号地址**上检查 loopback/private/link-local/multicast/metadata，并拒绝
  解析结果中任一私有地址（DNS 重绑定）；`CheckRedirect` 逐跳重新校验；MIME allowlist、大小上限、
  超时；请求**从不设置 Authorization**。正文经 `stripMarkup` 去标签。
- **B09-T09/T10 重排**（`rerank.go`）：`Rerank` 只对调用方 `Allowed=true` 的候选排序，权限/过滤
  不变，denied 候选即使得高分也不返回；同分用原 rank 稳定 tie-break；disabled / 无分数 / 越界
  分数一律**回退原序**并给出 reason；`RerankCacheKey` 含 query/filter/candidate+content revision/
  spec/model。
- **B09-T11/T12 提案**：`DraftProposal` 证据不足（<3）拒绝创建，状态恒为 `pending`，不直接改
  可执行词表；`ApproveProposal` 要求 pending、语义变更需稳定 ID，并区分 display-only（不重评）
  与定义变更（需受控重评）。
- **B09-T14/capability**：`internal/dashboard` 新增 `GET /api/extensions` 报告各 flag（默认全 off）
  且 `quality_verified:false`，避免假按钮。
