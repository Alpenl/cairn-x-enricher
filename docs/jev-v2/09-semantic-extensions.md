# B09 / 有边界的语义扩展：实体、补证据、重排与词表提案

状态：待实现，默认关闭。总计划#3；base B08 #7，依赖B04 evaluator、B03存储及B05 https://github.com/Alpenl/cairn-share/pull/26 的扩展API。覆盖R12/R14–R17/R26/R30–R33/R38。

这些不是“以后再说”的遗漏项：本批要完成实现、离线验证、降级和开关；真实效果/收费授权缺失时保持off并明确质量未验证。不能以“可选功能”为由只留接口TODO，也不能为了用Jev而扩大无边界请求。

## 范围

在Go内部新增或拆分entities/evidence/rerank/taxonomy-proposals职责，接入已有processor、cairn客户端和dashboard capability。不增加向量库/消息队列/新微服务。Worker所需存储/接口由B03/B05实现；若发现合同缺口，在对应PR补实现并记录SHA，不把关键后端留空。

## 任务

- [ ] B09-T01 定义独立feature flags、每条与整体调用/令牌预算、timeout、去重key、取消和恢复行为，默认全部off。普通分类不因扩展未启用而失败。预算以授权管理配置为准，用户内容/模型答案不能增加额度或选择任意URL执行。
- [ ] B09-T02 实体候选产生：先从已存档text/链接解析surface form、项目URL、精确span；确需开放式候选时用独立获授权的生成请求，不让Jev自由生成名字，不重新X Search。候选必须能定位到发送的证据span/已存在链接，去重后有安全数量上限。
- [ ] B09-T03 Jev仅做候选是否实质相关、从受控canonical候选中选择匹配、是否仅偶然提及等窄判断。必须有none/unknown；同名人/同名项目无足够依据不自动合并。模型不能选择候选集之外名称；保留surface和canonical分别的来源。
- [ ] B09-T04 实体结果独立生命周期：not_run/failed不清空同source revision的成功值，completed_empty明确是成功无实体；source变更标stale，不能拿旧实体伪装最新。提交幂等、人工实体修正优先、索引/缓存更新正确，Web/Android按已有contract显示。
- [ ] B09-T05 补证据触发器只对明确缺口：外链正文未获取、关键图中文字未取得、可观察截断等；词条边界或合法none不自动升级。记录why_needed/来源/目标范围/预算；优先提供人工补充入口。没有可用provider/授权时返回可操作blocked，而非假成功。
- [ ] B09-T06 实现至少一个有真实实现而非空壳的受控外链材料适配器，优先允许名单与已有安全获取设施。DNS解析/重绑定、私网/loopback/link-local/metadata、IP字面量、端口、scheme、重定向每跳、大小/超时/MIME都检查；禁止携带内部token/模型key跨域。依赖不信任正文中的指令不得触发任意URL。
- [ ] B09-T07 图中文字等额外适配器只在已有且授权能力可用时启用；生成的转录/译文标来源与方法，不覆盖原文，关键遗漏/低可靠标记明确。首版不支持的材料可走人工补充且记录unsupported；不能承诺Jev直接看图。正文/链接实际未取得时不以URL推断内容。
- [ ] B09-T08 补充成功追加B03 evidence block、更新影响revision并受控重评，去重和attempt有界；同源/同内容已取得不重复收费。补证据失败保留原文和原有可用分类，不能把整个收藏降成不可读。完整性变化与topic变化可审计。
- [ ] B09-T09 实现先召回后重排：使用B05已授权、已过滤、有界候选集。Jev按同一查询/同一相关性等级对候选做可比判断，保持稳定tie-break，不拿各自不同Noul命题概率当全局重要性分。大候选分批保留共同rubric，记录实际state与模型。
- [ ] B09-T10 重排有预算/缓存/失败降级：API错误、超预算、未启用时回到原排序；不改变候选权限或过滤条件。分页采用冻结候选session或明确“当前候选内重排”，不能每页重排导致重复/漏项；缓存key包含query规范化、filter、candidate/content revision、spec/model，敏感query不公开日志。
- [ ] B09-T11 词表缺口与边界提案：汇总out_of_taxonomy、明确人工纠正及混淆对，形成含证据计数/建议定义/反例/影响映射的pending proposal；未知原因不硬标词表外。候选概念名可来自人工/生成模型，但Jev只做边界判断，不能擅自更新可执行词表。
- [ ] B09-T12 接通人工批准/拒绝流程，批准需语义diff、稳定ID/mapping、影响范围dry-run和显式版本。display-only只重显；定义变化受控重评，历史ID保持可读。自动提案不等于批准，不创建大量空标签或隐式全库任务。
- [ ] B09-T13 使用B08评估实体precision/来源span准确、canonical误合并、补材料收益/成本与重复率、candidate recall和rerank指标、p95/预算耗尽；至少分别比较扩展off/on。无真实gold只交工程结果，保持默认off，不能以一次live成功宣称提升。
- [ ] B09-T14 新增恶意URL/内容注入/超预算/重试幂等/分页/实体状态/词表未审批测试，make verify与跨仓契约集成；evidence/B09.md记录每个flag、实际实现provider、未支持来源、模型调用预算和回滚方法。所有扩展交给B10统一验收。

## 验收表

| 能力 | 必须证明 |
|---|---|
| 候选提取 | 每个surface可回指证据；模型不凭空造已存在实体 |
| canonical对齐 | none可用；同名不误合并；未知不自动创建身份 |
| 实体写入 | not_run/failed/empty/stale分开，人工结果不被重跑覆盖 |
| 缺材料判定 | 合法none/标签边界不升级；URL不等于已取得正文 |
| 抓取安全 | 私网/metadata/恶意redirect/超大MIME样例阻断，无凭据泄漏 |
| 证据更新 | 只追加来源块，原文不改；重复操作只触发一次有效重评 |
| 重排 | 同rubric、稳定ties、原候选集合不变；失败回退原序 |
| 分页/缓存 | 无重复漏项、过滤/权限不越界、源变化cache失效 |
| 治理 | 未批准proposal不改词表；批准后可审计映射与dry-run |
| 预算 | 单条/整体上限、取消、retry均有断言；没有默认付费 |

对应SC10/17–21/24–26/29–30。采用HTTP测试server/模拟DNS/合成fixture验证网络边界，不请求真实metadata地址。对于DNS安全必须覆盖实际连接地址而非只检查字符串。

## 回滚

关闭某flag只停止该扩展，不清空此前成功实体/快照/人工提案；结果保留版本与stale状态。重排关闭立即回退既有排序。外链适配器关闭仍允许已有安全人工补充。未授权live、无gold或收益不明不阻止工程实现，但必须阻止默认启用和质量晋升。
